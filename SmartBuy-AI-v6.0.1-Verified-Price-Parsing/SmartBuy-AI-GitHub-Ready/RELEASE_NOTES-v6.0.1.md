# SmartBuy AI v6.0.1 — Verified Price Parsing

Цей патч виправляє критичну помилку, коли числа з назви або характеристик товару могли помилково ставати ціною. Наприклад `Sonnet 5/450x400` більше не може перетворитися на `450 грн`.

## Що змінилось

- Контекстний fallback приймає число як ціну лише коли воно явно має `₴`, `грн` або `UAH`.
- Числа з розмірів `450x400`, `950x500`, `30x30`, кількостей і моделей не вважаються ціною.
- Для відомих price-вузлів пріоритет мають `data-qaid`, `data-price`, `itemprop=price`, а не загальний текст картки.
- Структуровані ціни JSON-LD мають вищий пріоритет, ніж selector/context fallback при злитті дубльованих пропозицій.
- Доданий окремий `price-parsing audit` з регресійними тестами на прикладах Sonnet/Elite.
- Новий SQL у Supabase не потрібен.
