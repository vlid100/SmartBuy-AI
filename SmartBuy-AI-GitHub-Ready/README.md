# SmartBuy AI v0.3 — Ukraine Full Market

SmartBuy AI — Next.js/Vercel веб-застосунок для пошуку покупки одночасно в магазинах і на приватному ринку.

## Що змінилось у v0.3

- головний ринок — Україна;
- OLX / приватні продавці — окремий повноцінний сегмент, а не додаткова примітка;
- фільтри: **Усі / Нові / Б/в / Магазини / Приватні / Закордон**;
- окремі ціни **Нове від** та **Б/в від**;
- показ економії між новим і б/в;
- місто, дата оголошення, тип продавця й умови доставки для приватних пропозицій;
- прямий пошук одного й того ж запиту по українських джерелах: OLX, Rozetka, Prom.ua, Hotline, COMFY, Foxtrot, ALLO, Епіцентр, MOYO, TELEMART, BRAIN, Shafa;
- міжнародний блок підготовлений тільки для AliExpress, Temu та Amazon;
- Supabase-схема перероблена під `listings`, де є магазинні та приватні пропозиції.

## Важливо про v0.3

Кнопки джерел ведуть на **реальний пошук** на відповідному сайті. Об'єднані картки нижче поки є preview-даними, щоб спочатку правильно побудувати логіку нового/б/в, магазинів/людей, порівняння та інтерфейс.

Автоматичне збирання цін буде додаватися по одному джерелу через офіційний API, партнерський feed або інше дозволене стабільне джерело. Не варто будувати основу продукту на крихкому HTML-скрапінгу, який магазини можуть заблокувати або змінити будь-якої миті.

## Запуск локально

```bash
npm install
npm run dev
```

Відкрий `http://localhost:3000`.

## Vercel

Для v0.3 спеціальні API-ключі не потрібні. Якщо проєкт уже підключений до GitHub/Vercel, заміни файли в тій самій папці `SmartBuy-AI-GitHub-Ready` і зроби Commit — Vercel автоматично створить новий deployment.

## Supabase

Поки необов'язковий. Пізніше потрібен для:

- історії цін;
- відстеження між пристроями;
- акаунтів;
- сповіщень;
- кешу/нормалізації пропозицій з магазинів та приватних оголошень.

Схема знаходиться в `supabase/schema.sql`.
