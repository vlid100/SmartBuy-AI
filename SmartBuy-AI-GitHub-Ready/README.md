# SmartBuy AI — MVP 0.1

Перша версія веб-помічника для покупок: пошук природною мовою, категорії, фільтр за ціною, картки товарів, пропозиції магазинів, Smart Score, AI-висновок (поки демо), локальне відстеження та порівняння до 3 товарів.

## Запуск на Windows

1. Встанови Node.js LTS.
2. Відкрий папку проєкту у Terminal / PowerShell.
3. Виконай:

```bash
npm install
npm run dev
```

4. Відкрий http://localhost:3000

## Vercel

1. Завантаж проєкт у GitHub.
2. У Vercel натисни **Add New → Project** і вибери репозиторій.
3. Vercel сам визначить Next.js.
4. Натисни Deploy.

## Supabase — наступний крок

У `supabase/schema.sql` вже є базові таблиці: stores, products, offers, price_history, watchlist.

Коли створиш Supabase-проєкт:

1. Відкрий SQL Editor і виконай `supabase/schema.sql`.
2. Скопіюй `.env.example` у `.env.local`.
3. Заповни:

```env
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...
```

У Vercel ці самі значення додай у Project → Settings → Environment Variables.

## Що зараз демо

- Товари та магазини — тестові дані, не реальні ціни.
- AI-висновки — підготовлені демо-тексти.
- Порівняння поки має нижню панель; окрема сторінка буде в наступній версії.
- Відстеження зберігається у браузері через localStorage.

## Наступний етап

1. Підключити Supabase як реальну БД.
2. Додати імпорт товарів з першого реального джерела/API/фіда.
3. Нормалізувати однакові товари різних магазинів в одну картку.
4. Записувати історію цін.
5. Додати сторінку детального порівняння.
6. Додати AI-розбір запиту: категорія, бюджет, характеристики, пріоритети.
7. Додати акаунт і серверне відстеження ціни.

> Не додавай service-role чи інші секретні ключі у клієнтський код або GitHub.
